# GxE-of-Smoking-Initiation

## Overview
This repository contains code for analyses examining how the genetic architecture of smoking initiation (SI) varies across sex and generation. Using genetic association data from up to 4.9 million individuals across four ancestry groups, the study investigates how genetic influences on smoking initiation vary across biological and macrosocial contexts.
The analyses examine differences in SNP heritability, genetic correlations, and individual genetic effects across sex and generations, as well as the extent to which these patterns are shared across ancestries. We additionally conduct fine-mapping analyses to characterize potential causal variants underlying context-specific genetic associations. Together, these analyses provide evidence that the genetic architecture of smoking initiation is dynamic and sensitive to both biological and changing social environments.

## Data
The analyses in this study use customized data provided by the 23andMe Research Team. The data include GWAS summary statistics for smoking initiation stratified by sex, birth cohort, U.S. geographic regions, and genetic ancestry. Please see the Methods section of the paper for additional details.
Due to restrictions on the sharing of 23andMe participant data and derived genetic association results, the underlying data used in these analyses are not included in this repository. The repository therefore contains analysis code but does not contain the 23andMe GWAS summary statistics required to reproduce the analyses directly.
The code assumes that the required input files are stored locally in the corresponding data directories. File paths may need to be modified by users with authorized access to the relevant 23andMe data.
Researchers interested in accessing 23andMe data should contact 23andMe Research Institute directly regarding data access and research collaboration opportunities. Access to the data is subject to 23andMe Research Institute's data access policies, participant consent, and applicable approval requirements. The authors are not allowed to distribute the 23andMe data used in this study.

## Note
This repository does not contain plug-and-play code. The code is provided to document our analytical procedures and facilitate assessment of the reproducibility of our approach. Because the underlying 23andMe GWAS summary statistics cannot be publicly shared, the analyses cannot be reproduced directly using the materials provided in this repository. Users with authorized access to the relevant data may need to modify file paths and other data-specific settings before running the code.
